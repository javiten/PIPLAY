# Historial de cambios

## v1.0.0

- Primera versión en GitHub del reproductor aleatorio con biblioteca MP4 y panel local.
- Control manual de pantalla y programación por día, con horarios que pueden cruzar medianoche.
- AirPlay activable con PIN y botones de pantalla y AirPlay con iconos.
- Dashboard compacto, indicador fijo de espacio libre y secciones plegables.
- Selector de MP4 con carga automática, barra de progreso, validación previa de espacio y duplicados y mensajes de error más específicos.
